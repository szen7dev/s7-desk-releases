# S7 Bán hàng — bản cài đặt

Phần mềm Windows để tạo đơn, in tem, in bill và quản lý ca làm việc của S7.

## ⬇ [Tải bản mới nhất](https://github.com/szen7dev/s7-desk-releases/releases/latest)

Bấm link trên, rồi ở mục **Assets** bấm file `S7-Ban-hang-Setup-<phiên bản>.exe` để tải.

1. Chạy file vừa tải. Windows hiện cảnh báo màu xanh (phần mềm chưa ký số): bấm **"Thông tin thêm"** rồi **"Vẫn chạy"**.
2. Phần mềm tự cài và tự mở, không cần quyền quản trị.
3. Từ bản 0.1.3 trở đi, phần mềm **tự cập nhật**: bản mới tải ngầm, được cài khi tắt phần mềm.

Repo này chỉ chứa file cài. Phần mềm đọc thông tin bản mới từ đây.
